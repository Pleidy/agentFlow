# /agentflow spec — 需求规格编写

加载 `.claude/agentflows/skills/write-spec/SKILL.md` 技能定义。

## 模式

- **无参数** — 交互式构建 spec（逐步 Q&A）
- **<brief idea>** — 从简短想法构建完整 spec
- **<spec-path>** — 审阅并改进已有 spec

## 质量标准（五条准则）

每份 spec 必须通过：
1. **Bounded** — 范围明确，边界清晰
2. **Purposeful** — 有动机，解释 WHY
3. **Actionable** — 足够具体，可开始编码
4. **Verifiable** — 明确的 PASS/FAIL 判定标准
5. **Has outlet** — 知道「完成」是什么样子

严格按照 `.claude/agentflows/skills/write-spec/SKILL.md` 中的工作流执行。
